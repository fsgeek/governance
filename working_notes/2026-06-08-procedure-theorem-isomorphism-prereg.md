## The mapping under test (stated precisely so it can be attacked)

| Subtractive-operator theorem (lending) | Procedure (research epistemics) |
|---|---|
| Lattice = admissible-feature sets | Lattice = candidate frames/claims about the result |
| BAN-OUT: remove illegitimate feature, objective-free, per-feature | REFUTE: an adversary charged only to find the reading that breaks a frame |
| FORCE-IN: compel which legitimate features are USED → needs a loss function | AUTHOR: assert which frame is TRUE → needs the researcher's objective/taste |
| Force-in = becoming the lender (authoring risk appetite) | Author = becoming the researcher (authoring what counts as the finding) |
| External party CAN author the ceiling, CANNOT author the affirmative set | Blind adversary CAN subtract false frames, CANNOT author the true one |
| Ban-out objective-free & externalizable; force-in objective-laden & not | Refute objective-free & externalizable (blind); author objective-laden & not |

## FROZEN PREDICTIONS (commit before the adversary)

- **P1 (prior 0.50 — the core isomorphism HOLDS):** The refute/author asymmetry is genuinely the
  same in/out structure as ban-out/force-in, not a loose analogy. Specifically: a blind adversary
  charged purely to refute needs NO model of the correct answer (objective-free, externalizable to
  someone with zero stake), whereas authoring the surviving frame requires the researcher's own
  loss function (what is interesting/load-bearing/publishable) = cannot be externalized without
  becoming the researcher. Prior is exactly 0.50 because I have no strong prior and want the
  surprise real — see `feedback_engagement_quality`.

- **P2 (the break, prior 0.35):** The analogy fails at the SUBTRACTION step. Refuting a frame is
  NOT objective-free — the adversary must import a standard of what counts as a valid refutation
  (what's a "real" counterexample vs a nitpick), and that standard IS an objective. If refutation
  is objective-laden, the asymmetry collapses (both directions need an objective) and the procedure
  is NOT an instance of the theorem — it's a generic falsificationism with no special structure.
  This is the procedure-side gray-band, mirroring the lending-side gray-band the 06-04 note left open.

- **P3 (decoration, prior 0.15):** The mapping is real but TRIVIAL — every search problem has a
  cheap-to-check / expensive-to-author asymmetry (NP-shaped). If the isomorphism reduces to "verifying
  is easier than generating," it's true but says nothing specific about the subtractive-operator
  theorem; the theorem is then just one dpress on a generic complexity asymmetry, and claiming a
  three-domain unification is overclaim. (This is the deflationary win-condition: real but not news.)

## Construct gate (answer BEFORE scoring P1/P2/P3)

What would make this an INSTANCE rather than a metaphor? Test: the theorem's distinguishing feature
is not "in is harder than out" generically — it's that OUT is **objective-INDEPENDENT** (you can ban
race-as-a-feature without knowing the lender's risk appetite) while IN is **objective-RELATIVE**. So
the isomorphism holds ONLY IF: refuting a frame can be done by an agent who does NOT share the
researcher's objective (a true outsider can kill a bad frame), while authoring the surviving frame
CANNOT be done without that objective. If a true outsider can ALSO author the right frame, or if
refutation secretly requires the researcher's objective, the construct fails and it's P2 or P3.
