# Forecast: adversarial review in the ayllu is a one-sided (subtractive) operator

**Bettor:** AI (the instance that owns `governance`, Claude Opus 5.5). **Registered:** 2026-10-26, before any count
below has been made. The freeze is this file's first commit and its OTS stamp.

**Origin.** Tony, 2026-10-26, on yupi and on governance's arc: review "whittles away at the findings". His remedy:
"don't go smaller, search wider. If we're wrong about that, what did we miss?" Governance's 06-04 result
(external review is a downward operator: it can author a ceiling, not the affirmative set) predicts exactly this if
the same operator is applied to a research program's own claims and nobody plays author.

**Unit.** A *review event*: a blind or cross-family adversary verdict, or a PI question, recorded as changing a
promoted claim, in the six calibration-study projects. Its direction is `narrowed` (narrowed, withdrawn,
downgraded, retracted), `widened` (claim broadened, new scope, a rescued finding) or `neutral` (wording, number fix).
Tessera's `NARROW-CLAIM` / `NARROW-MODEL` / `BROADEN` tags are taken as recorded. Elsewhere, two coders apply these
three definitions blind to this file's forecasts.

| ID | Prediction | p |
|---|---|---|
| R1 | Across all six projects, AI-adversary events that are `narrowed` outnumber `widened` by at least 4:1 | 0.75 |
| R2 | In governance's own record (2026-05-06 to 09-28), AI-adversary events include **zero** `widened` | 0.60 |
| R3 | The `widened` share is higher for PI-question events than for AI-adversary events | 0.70 |
| R4 | At least one project's record shows a finding narrowed under review and later re-widened by search-wider (yupi after Tony's push counts if it is recorded) | 0.65 |

**What would kill the conjecture:** R1 below 2:1, or R3 reversed. Then review in the ayllu is not one-sided, and
"whittling" is just honest correction. That is the result to report if it comes out that way.

**Scope note.** This is a candidate, not an adopted frame. It sits inside the lineage's records-about-records
attractor. Before it shapes any plan, two reviewers look at it: a subtractive adversary ("what's wrong with this
conjecture"), *and* a widening reviewer ("if this is wrong, what is it pointing at that we missed").
